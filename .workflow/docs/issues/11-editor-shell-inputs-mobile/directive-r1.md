# Directive r1 — 모바일 하단 액션바 배치 조정 (#11)

**맥락:** 구현(`108dbf4`)은 정상 동작하나, 사용자 실브라우저 확인에서 **모바일 하단 액션바 레이아웃**에 대한 방향 변경 요청이 나왔다. 현재는 모바일에서 `PostEditorShell`이 세로 스택(`flex-col`)이라 `나가기`가 가운데 정렬로 홀로 한 줄을 차지하고, 그 아래에 `임시저장·출간하기`가 놓여 어색하다. 이 항목은 #11의 "하단 액션바 폰 대응" 범위 안이므로 레이아웃만 다듬는다.

## 변경 요청 (WHAT)
- **모바일 하단 액션바를 데스크톱처럼 "한 줄"로**: `나가기`는 왼쪽, `임시저장·출간하기` 묶음은 오른쪽으로 같은 행에 배치(`justify-between`). 현재의 세로 스택(나가기 단독 행 + 아래 클러스터)을 없앤다.
- **에러메시지는 버튼들과 같은 줄에 두지 말고 그 위 별도 전체폭 행**에 표시(현재도 이렇게 돼 있으면 유지). 인라인 배치로 되돌리지 말 것.
- **본문 하단 예약 공간(`pb`)을 새 한 줄 바 높이에 맞게 재조정**: 세로 2줄 기준으로 크게 잡아둔 예약(144px 등)을 단일 행 높이 + `env(safe-area-inset-bottom)`에 맞춰 줄이되, 에디터/본문이 고정 바에 가려지지 않도록 충분히 확보.

## 유지 (그대로 둘 것)
- 버튼 터치 타깃 높이(모바일 ≈44px, `sm:`↑ 기존 크기 복귀).
- `env(safe-area-inset-bottom)` 안전영역 반영.
- 데스크톱(`sm:`↑) 레이아웃은 기존과 시각적으로 동일.
- 이번 이슈의 다른 변경(제목 textarea/개행 정규화, 태그·삭제 버튼 터치 타깃, 반응형 에디터 height, dangerZone)은 그대로.

## 확인 포인트
- ~360–375px에서 `나가기` + `임시저장` + `출간하기`가 한 줄에 겹치지 않고 들어가는지(에러메시지는 위 별도 줄이므로 버튼 3개만 한 줄). 가장 좁은 폭에서 진짜로 빠듯하면 오른쪽 클러스터만 다음 줄로 wrap하되 `나가기`는 왼쪽 유지(graceful degrade)는 허용.
- 데스크톱 시각 회귀 없음.

## Scope
`components/PostEditorShell.tsx`, `app/admin/posts/new/NewPostForm.tsx`, `app/admin/posts/[id]/edit/EditPostForm.tsx`의 액션바 관련 클래스만. 그 외 파일/동작은 건드리지 않는다. plan.md의 나머지 요구·펜스는 그대로 유효.
